# Security Policy

## Supported Versions

We support security updates for the following versions of GSS.Authorization.OAuth:

| Version | Supported |
| ------- | --------- |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:       |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **DO NOT** create a public issue. Instead, report it responsibly:

* You can use the [GitHub Private Vulnerability Reporting](https://docs.github.com/code-security/security-advisories/guidelines-for-reporting-a-security-vulnerability) feature on the repository.
* Alternatively, email the maintainer directly (if email is provided in the profile).

Please include details about:
* The affected component/package and version.
* Steps to reproduce the issue.
* Any potential impact.

We will acknowledge your report within 48 hours and work with you to resolve the issue.
