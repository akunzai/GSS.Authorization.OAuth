# Contributing to GSS.Authorization.OAuth

Thank you for your interest in contributing to GSS.Authorization.OAuth! We welcome contributions from the community.

## Development Setup

To build and test the project locally, you will need:
* [.NET SDK](https://dotnet.microsoft.com/download) (latest version supporting .NET 8.0/10.0)

### Clone the Repository
```bash
git clone https://github.com/akunzai/GSS.Authorization.OAuth.git
cd GSS.Authorization.OAuth
```

### Build the Solution
```bash
dotnet build
```

### Run Tests
```bash
dotnet test
```

## How to Contribute

1. **Search for Existing Issues**: Before starting, check if a similar issue or pull request already exists.
2. **Create an Issue**: If you find a bug or want to propose a new feature, open an issue first to discuss it.
3. **Fork and Create a Branch**: Fork the repo and create your feature branch from `main`:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
4. **Follow Coding Standards**: Keep code consistent with the existing `.editorconfig` settings.
5. **Add Tests**: Ensure that your changes are covered by unit tests.
6. **Submit a Pull Request**: Submit your PR with a clear description of the changes.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project, you agree to abide by its terms.
